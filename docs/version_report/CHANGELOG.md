## v1.0.0（2026-01-30）

> 首个正式版本

### 新增功能

#### 用户系统
- [x] 用户注册与登录（JWT 认证）
- [x] 角色区分：教师 / 学生
- [x] 用户信息管理（姓名、学号）

#### 班级管理
- [x] 教师创建/编辑/删除班级
- [x] 班级状态切换（进行中/已结束）
- [x] 班级封面图上传
- [x] 班级日期管理（开课/结课）

#### 学生管理
- [x] 添加学生到班级
- [x] 批量导入学生（Excel）
- [x] 从班级移除学生
- [x] 学生名单搜索与筛选

#### 课程资源
- [x] 课程资源包管理
- [x] 课程章节与课时结构
- [x] 支持 PDF / PPT / 视频资源
- [x] 教师课程授权机制
- [x] 课程资源库展示（已授权/未授权区分）

#### 作业系统
- [x] 课程作业模板
- [x] 发布作业到班级
- [x] 学生提交作业（富文本 + 图片）
- [x] 教师批改作业（评分 + 评语）
- [x] 作业批注功能
- [x] 作业打回重新提交
- [x] 作业统计与待办提醒

#### 考试系统
- [x] 题库管理
- [x] 试卷编辑
- [x] 在线考试
- [x] 自动计时
- [x] 阅卷与评分
- [x] 成绩分析

#### 公告系统
- [x] 教师发布公告
- [x] 学生查看公告
- [x] 公告Widget展示

#### 学习进度
- [x] 课时学习进度跟踪
- [x] PDF 阅读位置记录

#### AI 集成（ComfyUI）
- [x] 实训环境管理
- [x] ComfyUI 队列代理
- [x] GPU 资源远程调用

### 技术特性

| 特性 | 状态 | 说明 |
|------|------|------|
| Redis 缓存 | ✅ | 课程章节、统计数据的缓存 |
| ID 加密 | ✅ | 对外使用 public_id 隐藏真实 ID |
| 文件上传 | ✅ | 头像、封面、作业附件 |
| Docker 部署 | ✅ | 完整容器化部署配置 |
| CORS 跨域 | ✅ | 支持多域名访问 |
